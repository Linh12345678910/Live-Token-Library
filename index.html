What's changed since the Confluence import

Confluence's "Unified Design System Tokens for Storefronts" is still the source of truth. Everything below is a deviation from it, grouped by why it changed. RB's brand-guide rebrand is the only sanctioned category of deviation — everything else is either a gap-fix (correcting the original import) or a brand-new addition.

Red Balloon corrections — verified against RB's live storefront or its own brand guide

  • Grey Scale/grey-25 (RB): #D5DEE4 → #D9D9D9. The Confluence value was never checked against RB specifically; #D9D9D9 was confirmed from a live product-tile card border.
  • Text/text-primary-light (RB): #FCF8F8 (Sea Foam) → #7C7C7C. Confirmed against the live crossed-out-price treatment on RB.
  • Brand/brand-accent-secondary (RB): Sea Foam #FCF8F8 → Azure Blue #C6E6FF. Sea Foam is restricted to "Text and Scribbles only" per RB's brand guide, so it wasn't a valid fit for a background/surface token.
  • Brand/brand-accent-secondary-dark (RB): previously reused Jam Jar (an unrelated hue) → #8BA1B3, a computed 30%-darker shade of Azure Blue.
  • Brand/brand-accent-dark (RB): previously undefined/not aligned with the accent family → #B3B377, a computed 30%-darker shade of Lemon Zest. RB's brand guide has no accent-dark swatch of its own, so this is a derived value.
  • Grey Scale/grey-150: deleted outright once its purpose moved to text-primary-light.
  • Brand/brand-primary-light / brand-primary-dark (RB): now read #FDEAE8 / #D8271B, matching the button hover/pressed-state recommendation from the live-evidence review — but flagged below as not yet confirmed/documented.

Cross-brand gap-fixes — correcting the original import, not deviating from it

  • Extra (try and avoid)/brand-accent-secondary-darker, ENZ: unset placeholder #000000 → #57585C (now consistent with EXOZ/ADR).
  • Extra (try and avoid)/ui-light-yellow: created — didn't exist in the file before. EXOZ/ENZ = #FFF67A.
  • Extra (try and avoid)/ui-dark-blue: created — same gap. EXOZ/ENZ = #013378.
  • Extra (try and avoid)/font-family-display: created — ENZ = Bicyclette (its H1 typeface).

New scales added this project — not part of the original Confluence import

  • Font-size scale (9 tokens: font-size-body-xxs through font-size-h1, plus a duplicate-named font-size-body-xs 2): added for RB and the other four brands. Currently identical across all five brands — worth confirming whether any brand needs different sizing.
  • Corner-radius scale (4 tokens: radius-default, radius-button, radius-large, radius-small): added for all five brands. EXOZ/ENZ (64px) and LA (6px) match the codebase usage audit's documented button corner radius exactly; ADR (2px) doesn't — the audit records ADR's shipped value as 4px (see Open Issues).

Open issues found while compiling this — not yet resolved

  • brand-primary-light / brand-primary-dark (RB) authorship unconfirmed. Current values match the agreed button hover/pressed recommendation, but were applied directly in Figma outside the tracked edit process — no description recorded, no confirmed author.
  • Duplicate Layout/border-primary variables. Two variables exist with the same base name — one aliases to Backgrounds/bg-black, the other (auto-suffixed "2" by Figma) aliases to Grey Scale/grey-25. Needs a decision on which is correct.
  • Duplicate font-size-body-xs naming. Shows up as "font-size-body-xs 2" — a naming collision that needs cleanup.
  • ADR corner radius mismatch. Figma's radius-default/radius-button/radius-small show ADR = 2px; the codebase usage audit records ADR's actual shipped primary-button radius as 4px.
  • Text/text-primary EXOZ mismatch. Figma shows EXOZ = #000000, but the usage audit records EXOZ's real shipped value as #1A1D1E (and ENZ, which mirrors EXOZ's code, correctly shows #1A1D1E — so EXOZ doesn't even match its own mirror).
  • Extra/font-family-fancy ENZ bug. Currently reads "Bicyclette", which belongs to the separate font-family-display token (ENZ-only). font-family-fancy is ADR-only ("Monologue") — ENZ here should read "n/a".
  • Typography/font-weight-semibold (RB). A fix from 500→600 (to give Inter a genuine semibold) was discussed but never actioned — currently sits at 600, so this one is actually already correct; listed here only because it was an open thread.
  • Text/text-primary-light (RB) consolidation. A recommendation to move RB from #7C7C7C to #58575B (matching ADR/LA, consolidating several near-duplicate live greys) was made but never confirmed/executed.
